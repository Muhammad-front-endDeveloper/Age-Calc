# Age Calculator

A simple age calculator built with HTML, CSS, and JavaScript.

## Description
This project calculates your age in years based on your date of birth.  
Built to practice working with the JavaScript Date object.

## Features
- Calculates age in years
- Simple and clean UI
- Responsive design for mobile and desktop

## Live Demo
- **Netlify**: https://simple-age-calculator1.netlify.app/
- **GitHub Pages**: not yet set

## How to Use
1. Enter your date of birth
2. Click "Calculate"
3. Your age in years will be displayed

## Technologies Used
- HTML5
- CSS3
- JavaScript
